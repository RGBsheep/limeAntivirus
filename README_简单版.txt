【一分钟上手】

1. 双击 "启动青柠杀毒.vbs" 运行程序

2. 点击 "快速扫描" 开始扫描C盘

3. 点击 "广告拦截" 可屏蔽广告（需管理员权限）

4. 关闭窗口即可退出程序

【常用功能】

🔍 快速扫描 - 扫描C盘系统目录

📁 自定义扫描 - 选择指定文件夹

📦 隔离区 - 管理被隔离的文件

🛡️ 广告拦截 - 屏蔽广告域名和弹窗

【注意事项】

⚠️ 首次运行安装依赖，需要联网

⚠️ 广告拦截需要管理员权限

⚠️ 建议以管理员身份运行获得完整功能
