========================================
    青柠杀毒 LS - 使用说明
    Lime Antivirus - User Guide
========================================

【软件简介】
青柠杀毒是一款免费、轻量的Windows安全防护软件。
提供病毒扫描、实时监控、弹窗拦截、广告过滤等功能。
界面简洁清新，资源占用低。

【主要功能】
✅ 病毒扫描 - MD5+特征码多重检测
✅ 实时监控 - 自动检测新文件
✅ HIPS防护 - 可疑进程行为分析
✅ 弹窗拦截 - 自动关闭广告窗口
✅ DNS拦截 - 屏蔽广告域名（需管理员权限）
✅ 隔离区 - 安全隔离威胁文件

【系统要求】
- Windows 7 / 8 / 10 / 11
- Python 3.7 或更高版本
- 建议内存 2GB 以上

========================================
           安装与运行
========================================

【方法一：直接运行（推荐）】
1. 双击运行 "run.vbs" 或 "run.bat"
2. 程序将自动安装依赖并启动
3. 关闭CMD窗口不影响程序运行

【方法二：命令行运行】
打开CMD，进入程序目录，执行：
    python main.py

========================================
           使用说明
========================================

【病毒扫描】
- 快速扫描：扫描C盘常用目录
- 自定义扫描：选择任意文件夹进行扫描
- 扫描时可随时停止

【实时监控】
- 自动监控下载目录和临时目录
- 发现新文件自动扫描
- 高威胁文件自动隔离

【弹窗拦截】
- 程序启动后自动启用
- 自动检测并关闭广告弹窗
- 可在日志中查看拦截记录

【广告拦截】
点击"广告拦截"按钮：
- 启用DNS/hosts拦截（需要管理员权限）
- 将广告域名指向本地，从源头屏蔽
- 支持自定义添加拦截域名

【隔离区】
- 查看所有隔离的文件
- 恢复被隔离的文件
- 永久删除确认威胁

========================================
           测试病毒
========================================

创建测试文件 eicar.com.txt，内容：
X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*

扫描此文件会被检测为 "EICAR-Test-File"
这是国际公认的杀毒软件测试标准，无害。

========================================
           常见问题
========================================

Q: 运行提示"python不是内部命令"？
A: 请先安装Python：https://python.org
   安装时勾选"Add Python to PATH"

Q: 广告拦截提示需要管理员权限？
A: 右键以管理员身份运行程序，或右键VBS选择"以管理员身份运行"

Q: 扫描速度慢？
A: 首次扫描较慢属正常现象。可暂停扫描或选择自定义目录。

Q: 弹窗拦截误判怎么办？
A: 程序只拦截包含广告关键词的窗口，误判率很低。
   如有误判请在日志中查看并反馈。

Q: 如何彻底卸载？
A: 删除程序文件夹即可，无注册表残留。
